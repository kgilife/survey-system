# 05｜管理、統計、庫存與匯出

## 1. 專案管理分頁

現行專案管理包含 10 個分頁：

1. 專案設定
2. 使用者設定
3. 問卷設計
4. 填寫狀況
5. 回答資料
6. 統計分析
7. 庫存管理
8. 附件管理
9. 分享設定
10. 操作紀錄

## 2. 填寫狀況與回答

- 顯示總人數、已登入、已暫存、已送出與填寫率。
- 管理員可開啟指定使用者回答，代為暫存或送出覆蓋。
- 管理員將已送出回答改回暫存時，應歸還該回答占用的庫存。

## 3. 統計分析

- 依使用者欄位中勾選的統計維度分組。
- 顯示各組人數、送出數及填寫率。
- 熱點題疊加所有已送出座標。
- MaxDiff 顯示相對效用：`(最偏好次數－最不偏好次數)／顯示次數`。

## 4. 庫存管理

- 用於活動名額、商品數量、預約時段等有限資源。
- 庫存題各選項保存初始庫存與剩餘庫存。
- 暫存不占用名額；正式送出才扣除。
- 後端在鎖內再次檢查庫存，避免多人同時超賣。
- 管理員可用正負整數手動調整，所有異動保存前後數量、操作者、原因與時間。
- 沒有庫存題時，頁面須解釋用途並引導管理員先建立限量／庫存題，不只顯示「沒有資料」。

## 5. 附件管理

列出帳號、題目、附件類型、檔名、Drive 檔案 ID、大小、MIME、上傳時間與有效狀態。附件下載必須經授權 API。

## 6. 分享與匯出

- 分享頁提供專案登入網址、複製、QR Code 與預覽登入頁。
- 「回答資料」右上方僅保留一顆「↓ 下載問卷結果」，下方提示「Excel，包含全部填答者」。移除原本的問卷分析總表、僅已送出、矩陣展開表、完整明細四顆按鈕；不新增下拉選單、篩選器或下載區塊，下方回答資料表不變。
- 按一次直接產生 `<專案ID>_問卷結果.xlsx`，含以下工作表：

| 工作表 | 列與欄規則 |
|---|---|
| 回答總覽 | 全部填答者一人一列；帳號、使用者欄位、填寫狀態、一般題答案；矩陣題欄提供工作表跳轉連結。 |
| 已送出總覽 | 與回答總覽相同欄位，只列目前填寫狀態為「已送出」者；無資料時保留表頭。 |
| Q序號_矩陣題名稱 | 每道連結型矩陣、單選方格、核取方塊格各一張；每位填答者每個項目一列。連結型矩陣的子問項各一欄，一般方格為項目名稱與答案。無矩陣題不建立此類工作表。 |
| 完整答案明細 | 帳號、使用者欄位、填寫狀態、題號、題目名稱、項目名稱、子問項、答案、題目／項目／子問項 ID、最後更新、送出時間。一般題每人每題一列；矩陣題逐項逐子問項展開，連結型簡答逐項展開。 |

- 未填寫答案留白；未獲配連結型項目者不產生虛構矩陣列。仍有答案但已移除的項目保留 ID；已移除題目與不在現行名單的既有回答保留於完整明細，不靜默丟棄。
- 使用者欄位按設定順序，表頭使用中文顯示名稱。未設定且全空白的殘留欄位不匯出；`field_N` 這類未命名且全空白的自動欄位，即使仍留在欄位設定也排除。正式命名的有效空欄位仍保留，有內容的舊欄位不因未設定而丟失；不修改原始資料。
- 密碼、密碼雜湊及密碼型自訂欄位不得匯出。選項與項目盡可能顯示名稱，沒有對應名稱才保留原 ID；連結型名稱按填答者帳號配對，不得誤用其他人的同 ID 名稱。
- 帳號以文字儲存以保留前導零；答案以文字儲存，包含 `=` 開頭的內容也不得變成公式。保留中文與換行，各表有表頭、凍結首列／帳號欄及篩選功能。
- 工作表名稱移除 Excel 禁用字元、限制 31 字元且不重複。超過 Excel 列欄或單格字數上限時明確報錯，不靜默截斷。
- 點擊時重新透過既有授權的專案與回答 API 讀取最新資料；Excel 程式按需載入並在瀏覽器產生，不建立暫存 Google Drive 檔案，也不需新增資料表或後端部署。產生中停用按鈕並顯示「產生 Excel 中…」，失敗後可重試。
- 其他管理分頁與既有後端 CSV API 保留相容，不在回答資料頁另增 CSV 入口。既有 CSV 採帶有 BOM 的 UTF-8（`\uFEFF`），避免 Excel 中文亂碼；本次新欄位清理規則適用整合後 Excel。


## 7. 操作紀錄

重要管理行為、登入、專案異動、回答覆蓋、庫存調整及填寫者送出均應留下時間、操作者、動作、對象與說明。
