# 01｜系統範圍與架構

## 1. 系統目標

提供具有身分驗證、個別名單、分段問卷、特殊題型、暫存、正式送出、統計、匯出、附件與稽核紀錄的問卷管理平台。

## 2. 使用者角色

### 管理員

- 註冊、登入、重設密碼及維護個人資料。
- 建立、複製、設定及刪除自己的專案。
- 匯入填寫者、設計題目、查看狀態、回答、附件、統計、庫存與操作紀錄。
- 代填或修改使用者回答。

`system_admin` 為系統管理角色；一般註冊帳號角色為 `user`。每位管理員只能存取自己擁有的專案。

### 問卷填寫者

- 由專案專屬網址進入。
- 根據專案設定的存取模式（`access_mode`）：
  - **指定使用者**：需使用該專案名單中的帳號與密碼登入。
  - **開放所有人填寫**：免登入直接進入，系統自動配發訪客身分（`guest_UUID`）綁定裝置。
- 在允許期間作答、暫存、正式送出或查看既有回答。
- 開放問卷模式下，跨裝置或清除快取時可使用專屬「接續網址」找回進度。

## 3. 系統元件

```text
瀏覽器
  └─ GitHub Pages：React 前端
       └─ HTTPS POST
            └─ Google Apps Script Web App
                 ├─ 主資料 Google Sheet
                 ├─ 專案 Google Sheet（每專案一份）
                 ├─ Google Drive 專案資料夾與附件
                 └─ MailApp 密碼重設信
```

## 4. 路由

- `/`：立即導向 `#/admin/login`，不顯示中介首頁。
- `#/admin/login`：管理員登入。
- `#/register`：建立管理員帳號。
- `#/forgot-password`、`#/reset-password`：重設密碼。
- `#/profile`：管理員個人資料與密碼設定。
- `#/admin`：管理員專案列表。
- `#/admin/projects/{projectId}`：專案管理。
- `#/survey/{projectId}/login`：填寫者登入。
- `#/survey/{projectId}`：填寫問卷。

## 5. 儲存隔離

- 主資料庫保存管理員、專案索引、系統設定、密碼重設與系統操作紀錄。
- 每個專案使用獨立 Google Sheet，保存題目、選項、使用者、回答、附件、庫存及操作紀錄。
- 每位管理員有獨立 Drive 資料夾；每個專案再建立自己的資料夾。
